The new [sync/v2] package provides typed synchronization primitives. It
includes the generic [Map] and [Pool] types, and aliases and convenience
functions for primitives from [sync].

[Pool.GetOK] reports whether a value was obtained, distinguishing an empty
pool without a New function from a stored zero value. It reports success for
values returned by New, including zero values.
