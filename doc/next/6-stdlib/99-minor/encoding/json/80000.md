The new generic functions [MarshalOf], [MarshalIndentOf], [AppendMarshal],
[AppendMarshalOf], [AppendMarshalIndent], [AppendMarshalIndentOf],
[UnmarshalOf], [EncodeOf] and [DecodeOf] provide type-safe variants of the
existing marshaling and unmarshaling APIs, and allow appending encoded output
to an existing buffer.
