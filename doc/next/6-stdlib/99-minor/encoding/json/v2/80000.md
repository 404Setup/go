The new generic functions [MarshalOf], [MarshalWriteOf], [MarshalEncodeOf],
[AppendMarshal], [AppendMarshalOf], [UnmarshalOf], [UnmarshalReadOf] and
[UnmarshalDecodeOf] provide type-safe variants of the existing marshaling and
unmarshaling APIs, and allow appending encoded output to an existing buffer.
