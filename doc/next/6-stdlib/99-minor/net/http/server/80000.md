The new [net/http/server] package provides a structured HTTP server wrapper
built on [net/http].

It provides [Server] and [Group] for method-based static, parameterized
(`{param}`), and catch-all (`{wildcard...}`) routing, [Context] for pooled
request state, parameter/query parsing, bounded JSON/form/multipart decoding,
and response helpers, [HTTPError] and [ErrorHandler] for centralized error
handling, static file serving confined with [os.OpenRoot] via
[Server.StaticDir] and [Server.StaticFS], graceful lifecycle management via
[Server.ListenAndServeContext], [Server.ListenAndServeTLSContext],
[Server.ServeContext], and [Server.ServeTLSContext], and built-in middleware
including [Recover], [Logger], [LoggerWithConfig], [RequestID], [BodyLimit],
[Timeout], [MaxInFlight], [SecurityHeaders], [CORS], [CrossOriginProtection],
[BasicAuth], [Compress], [CompressWithConfig], and [Adapt].
